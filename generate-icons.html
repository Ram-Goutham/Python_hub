PyHub Icon Generator

Click the button to download all icon sizes. Save them into an icons/ folder in your website directory.

Steps after downloading:

  1. Create a folder named icons inside your website folder
  2. Move all downloaded icon-*.png files into icons/
  3. Commit and push to GitHub: git add icons/ && git commit -m "Add PWA icons" && git push
  4. Go back to PWABuilder and re-scan — all icon errors will be gone ✅
